# Datasets

`sample_emails.csv` is **synthetic** (generated by `tools/make_sample_data.py`). It exists only so the app
and tests run immediately. Scores on it are unrealistically perfect - do **not** report them as your results.

## Use a real dataset for the final submission

1. Download a labelled phishing-email dataset, for example:
   - Kaggle: "Phishing Email Detection" (`Phishing_Email.csv`, columns *Email Text*, *Email Type*)
   - Kaggle: "Phishing Email Dataset" (Nazario / Enron / SpamAssassin collections)
   - Nazario phishing corpus and SpamAssassin public corpus (raw mail archives)
2. Put the file in `data/raw/` and convert it:
   ```
   python prepare_dataset.py data/raw/Phishing_Email.csv
   ```
   This writes `data/emails.csv` (columns `subject, body, label`; 1 = phishing, 0 = legitimate),
   normalises labels, removes empty rows and duplicates.
3. Retrain: `python train.py` (it automatically prefers `data/emails.csv`).
4. Commit the refreshed `models/` folder so a deployed app starts instantly.

Record in your report: dataset name, URL, licence, size, class balance, and any cleaning you did.
